# research/reports: dữ liệu và báo cáo nghiên cứu thị trường

Nhánh này **chỉ chứa dữ liệu và báo cáo**. Máy tự ghi vào đây, nên không merge nhánh này vào `main`.
Code nằm ở `market_watch.py` trên nhánh code.

| Thư mục | Nội dung | Ai ghi | Khi nào |
|---|---|---|---|
| `data/YYYY-MM-DD/` | `discovery.csv`, `channels.csv`, `videos.csv`, `run.json`, `TOM_TAT.md` | GitHub Actions | Hằng ngày, khoảng 15:17 giờ VN |
| `reports/YYYY-Www/SO_LIEU.md` | Số liệu tuần: bảng chấm ô, đối thủ, video bung | GitHub Actions | Chủ nhật |
| `reports/YYYY-Www/BAO_CAO_DOI_THU.md` | Báo cáo đối thủ, đề xuất tuyến nội dung, việc cần làm | Claude theo lịch | Chủ nhật tối |
| `state/channels.csv` | Danh sách kênh đang theo dõi | GitHub Actions | Hằng ngày |

Bắt đầu đọc từ [reports/INDEX.md](reports/INDEX.md).
