## Shot module
```js
import { E, V, registerShot, ease, clamp, lerp, wordTime, text } from '/engine/core.js';
import * as UI from '/engine/ui2d.js';  import * as D from '/engine/diagrams2d.js';
import { PLACES, CAST, EXPR, who } from '../_places.js';
registerShot('s048', { init(T, info) { …; return s; }, draw(s, t, info, T) { … }, overlay(g, t, info, s) { … } });
registerShot('s121', { kind: '2d', draw(g, t, info) { D.stage2d(g); … } });   // flat 2D card ("backdrop" in shots.json to sit on a blurred shot)
```
`info = { dur, globalT, p, line, shot }` (`info.shot` = the shots.json entry). `draw` must be pure in t: no `+=`, no Math.random/Date.now (`T.rng(seed)` in init).
Return every moving object from init (or set `obj.userData.dynamic = true`), else the static merge freezes it.
`V(h, v)` picks the 16:9 / 9:16 value. Overlay space is 1920×1080 (`E.W`, `E.H`); keep text between y 90 and 990.
`wordTime('fifty', afterGlobalSec)` → global time of a spoken word (null if not found); local = result − (info.globalT − t).
The first draw of a shot: run the draw body twice (`if (!s.pre) { s.pre = 1; body(); } body();`): the rig's first solve is not settled.

## Stage, look, weather
`const st = T.stage({ mood: 'night' | 'day', fov: V(36, 50) })`: the shot's `look`/`weather` in shots.json are applied by themselves.

## Characters (`CAST` ids)
`CAST`: <HERO> <ids…> X1…Xn (crowd). <the video's glow / signature device and its rule>
```js
const ch = st.add(T.character(CAST.<HERO>, { seed: 3 }).place(x, y, z, yaw));   // yaw 0 faces +z (camera side), π/2 faces +x; ch.faceTo(x, z)
let p = T.posesAt3(t, [[0, 'stand'], [0.9, 'point']]);            // or a name / { ...T.POSES3.stand, armL: { to: [x, y, z] } }
p = T.idle3(p, t, { seed: 2, k: 1 });  p = T.speak3(p, '<SPEAKER>', info.globalT, { hand: false });   // hand:false on kneel/crouch/sit poses (arm snaps)
p = T.walkTo(ch, t, { from: [x, z], to: [x, z], t0, t1, run, idle: p, end: 'stand', yaw1 });     // moves + turns ch, returns the pose
ch.pose(p);  T.lookAtSpeaker(ch, { <SPEAKER>: s.other }, info.globalT);  ch.lookAt3([x, y, z], 0.8);
ch.face({ expr: [[0, 'deadpan'], [1.2, 'shocked']], t, blink: true, speaker: '<SPEAKER>', gt: info.globalT });
ch.hold(obj, 'R', { rot: [0, 0, 0] });  ch.headWorld();  ch.handWorld('L');  ch.chestWorld();  ch.updateMatrixWorld(true)  // before handWorld
```

## Camera
`T.camShot(st.camera, t, name, { a, b, dur: info.dur, side: ±1, dist: 1, fov, avoid: false, at })` — names: establish craneDown wide full medium twoShot ots closeup xcu pushIn pullBack lowHero high dutch orbit track reveal insert (o.at = point/object). Close framings set dof by themselves.
`T.dolly(cam, t, [[0, { pos, look, fov }], [dur, { pos, look, fov }]])` · `T.aim(cam, [x,y,z], { dist, yaw, pitch, fov })` · `T.crashZoom(cam, t, { at, dur: 0.2 })` · `T.punch(cam, t, at, { amp })` · `T.shake(cam, t, amp)` · `T.rackFocus(st, t, [[0, a], [1.6, b]], 0.45)`.
Establishing inside a room: dolly between the place's `est` points (camShot 'establish' starts in the ceiling).
